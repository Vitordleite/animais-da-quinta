# 🐮 Jogos das Pequenitas

Jogos para a Benedita e a Mafalda. Primeiro jogo: **Os Animais da Quinta**.

Jogo para crianças pequenas, em português de Portugal. Corre no browser (telemóvel, tablet ou PC), sem instalar nada e sem internet.

- 👆 **Toca e ouve** – toca num animal e ouve o som
- 👂 **Que animal é?** – ouve o som e escolhe o animal
- 🔎 **Onde está?** – ouve o nome e encontra o animal

Os sons são sintetizados no próprio browser (Web Audio), por isso são aproximações dos sons reais.
